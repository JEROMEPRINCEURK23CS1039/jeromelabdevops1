# jeromelabdevops1

## Exp No. 1: Git Essentials – Commit, Push, Merge, and Pull Requests

### Aim
The aim is to demonstrate pushing changes to a GitHub repository, covering setup, managing visibility, and executing basic Git operations.

### Description
1. **Setting up Git**: Ensure Git is installed.
2. **Managing Repository Visibility**: Private vs Public.
3. **Changing Repository Visibility**: Setting visibility on GitHub.
4. **Pushing Changes**: Local changes, commits, and pushing to remote.

### Git Basic Commands
- `git init`
- `git clone`
- `git add`
- `git commit`
- `git status`
- `git log`
- `git branch`
- `git merge`
- `git remote`
- `git push`
- `git pull`
